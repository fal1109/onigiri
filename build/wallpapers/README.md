# Built-in wallpaper collections

Two collections ship inside the app and show up in Settings → Extras →
Wallpapers as drop-down menus:

- `fal/` — the "Fal" collection
- `rui/` — the "Rui" collection

Drop files straight into the matching folder — images (`png`, `jpg`, `jpeg`,
`webp`, `gif`, `avif`, `bmp`) or short video clips (`mp4`, `m4v`, `webm`,
`mov`, `ogv`, `mkv`; anything Chromium can play). Videos loop muted as the
app background, with the same blur and parallax as image wallpapers. Files
are listed sorted by filename, shown as a 3-column grid (videos preview as
their first frame), and clicking one applies it as the app background
instantly. Restart the app after adding new files so they get picked up.

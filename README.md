

# onigiri
watch together app that downloads the videos so no one suffers from internet lag hopefully

## requirement

1. **yt-dlp** — the app shells out to it to download videos from a link.
   - Linux: `sudo apt install yt-dlp` [debian]  (or `pip install -U yt-dlp`)
            `sudo pacman -S yt-dlp` [arch]
   - Windows: powershell as administrator; `winget install yt-dlp.yt-dlp`
2. **ffmpeg** — needed by yt-dlp to merge separate video/audio streams into one file.
   - Linux: `sudo apt install ffmpeg` [debian]
             `sudo pacman -S ffmpeg` [arch]
   - Windows: powershell as administrator; `winget install Gyan.FFmpeg -e`
